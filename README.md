# 📊 Social Media Influencer Campaign Performance Analysis

## 📌 Project Overview

This project focuses on analyzing social media influencer marketing campaigns using Python and Power BI. The objective is to evaluate campaign performance, measure marketing effectiveness, and provide data-driven insights that help businesses optimize influencer marketing strategies.

The project includes data preprocessing, KPI calculation, campaign analysis, influencer segmentation, and interactive dashboard development.

---

# 🎯 Problem Statement

Brands invest heavily in influencer marketing campaigns to promote their products and services across various social media platforms. However, measuring campaign success and identifying high-performing influencers remains a challenge.

This project aims to build an Influencer Campaign Performance Dashboard that enables marketing teams to monitor campaign effectiveness, evaluate Return on Investment (ROI), analyze engagement, compare platform performance, and make better business decisions.

---

# 📂 Dataset Description

**Dataset Type:** Social Media Campaign Dataset

**Dataset Format:** CSV

**Number of Records:** 10,000+

### Dataset Features

- Campaign ID
- Campaign Name
- Platform
- Influencer Type
- Followers
- Reach
- Spend
- Revenue
- Engagement Rate
- ROI
- Audience Group
- Conversion Rate

The dataset contains campaign performance metrics collected from different social media marketing campaigns.

---

# 📈 KPI Definitions

The following Key Performance Indicators (KPIs) were created for performance evaluation.

| KPI | Description |
|------|-------------|
| Total Campaigns | Total number of campaigns |
| Total Reach | Total audience reached |
| Total Revenue | Total revenue generated |
| Total Spend | Total campaign spending |
| Average Engagement Rate | Average engagement across campaigns |
| Average ROI | Average Return on Investment |
| Cost Per Engagement | Marketing cost per engagement |
| Conversion Rate | Percentage of successful conversions |

# 🔍 Key Findings

- High ROI influencers generated better campaign profitability.
- Instagram and TikTok demonstrated higher audience engagement.
- Higher campaign spending generally increased reach and revenue.
- Audience engagement varied across different audience groups.
- Interactive dashboards simplified campaign performance monitoring.

---

# 💡 Recommendations

- Invest more in high ROI influencers.
- Allocate marketing budgets to high-performing platforms.
- Improve campaigns with lower engagement.
- Monitor KPIs regularly for better decision-making.
- Focus on audience groups with higher conversion rates.
